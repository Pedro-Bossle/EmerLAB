# Assinaturas de e-mail (EmerLAB / Emerdog)

Pasta para HTML de assinaturas oficiais da plataforma.

- `emerlab.html` — assinatura padrão EmerLAB
- `emermarketing.html` — assinatura EmerMarketing

## Uso

1. Edite o HTML desta pasta para ajustar texto, telefone ou links.
2. Os e-mails transacionais (Resend) montam a assinatura em código (`api/_lib/emailAssinaturas/`), usando as mesmas cores e logos (`/email/logo-azul.png`, `/email/logo-branco.png`).
3. Para clientes de e-mail (Outlook / Gmail), copie o conteúdo do `.html` em **Inserir → Assinatura**.
